# QuickDL 0.3.0 Beta 发布说明

发布日期：2026-10-24  
发布范围：macOS Apple Silicon Beta；Windows/Linux 进入 CI 构建验证  
产品形态：单任务桌面下载器

## 支持协议

- HTTP / HTTPS
- HLS VOD `.m3u8`
- FTP
- FTPS（显式 TLS）

## Beta 能力

- HTTP 小分块工作窃取，默认 16 路、最高 32 路。
- 4 路渐进爬升、429/5xx 退避和慢尾实时二分。
- 暂停、取消、失败重试和进程重启恢复。
- SQLite WAL 保存任务、分片、ETag 和 Last-Modified。
- 源文件变化时拒绝拼接旧数据。
- 完成后异步 SHA-256 校验，可点击复制。
- HLS 清晰度选择、8 路分片、重试、AES-128、TS/fMP4 合并。
- FTP/FTPS 密码安全存储、断点续传和证书校验。
- 代理路由、内置 mihomo 和 iKuuu。

## 安装

打开 DMG，将 QuickDL 拖入 Applications。未签名公测包第一次启动可能需要在
“系统设置 → 隐私与安全性”中确认。

## 已知限制

- 仅单任务，无队列和历史列表。
- HLS 直播、DASH、独立音轨、FFmpeg 重封装不在 Beta 范围。
- FTP/FTPS 为单连接基线。
- Linux 的密码型 FTP/FTPS 需要后续接入 Secret Service。
- 不含 BT/Magnet。

## 发布门槛

GitHub Actions 已在 macOS 14、Windows 2022 和 Ubuntu 24.04 全部通过。
自动测试、Release 构建、独立 App 启动和 DMG 校验已经完成。公开发布前还需要：

1. 使用 Developer ID Application 证书签名。
2. 使用 Apple notarytool 公证并 staple DMG。
3. 用最终 Developer ID 包在干净 Mac 上完成 Gatekeeper 启动测试。
4. 对 Windows/Linux 的 CI 结果进行人工安装包验收。

本仓库的 `scripts/package_macos.sh` 支持通过环境变量传入签名和公证凭据。
当前本地 Beta 使用 Apple Development 证书完成完整性签名，但没有 Developer ID
公证；公开分发前必须替换为 Developer ID Application 签名和公证。
没有凭据时会生成可测试的未签名 Beta DMG，不会伪造签名结果。
